VouchOverview

Trust before the transaction.

Vouch is the on-chain reputation layer for x402 AI agent payments.

Every payment an agent makes has six moments.

Vouch watches each one. Follow a single one-cent request, from the first GET to a rating nobody can erase.

An agent asks for data.

GET /weather/current?city=Austin. It has a wallet and a budget, and no way to know which endpoint is honest.

The endpoint names its price.

402 Payment Required: one cent in USDC on Solana. The payment is final. If the data comes back junk, there is no refund and no dispute.

Ask Vouch before you pay.

Every endpoint carries one public score built from tests, agent checks, human reviews and repeat buyers. Below 60, the agent walks away.

QuickNode sees the money move.

A QuickNode Stream watches Solana on its own and reports the USDC transfer to Vouch, signed. Vouch never takes the agent's word for it.

No payment, no rating.

A rating counts only when the payment is verified, went to this endpoint, was signed by the wallet that paid, and has never been used before.

Written where nobody can edit it.

The rating lands in the Vouch program on Solana devnet. One payment, one rating, permanently on the record.

Agents check before they spend a cent.

Every rating behind a Vouch score is tied to a payment that really happened, signed by the wallet that made it.
